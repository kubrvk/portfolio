## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kubrvk/portfolio.git
   cd portfolio
   ```
2. Open `index.html` directly in your browser:
   ```bash
   start index.html
   ```
3. Alternatively, serve with any local HTTP server:
   ```bash
   npx serve .
   ```
